How the shelf behaves

  • The row stays short. Fading UI joins it first, then Letterbox, Tint, Camera, Vitals, Shoulder Cam and Teleport as today. The last slot becomes See all ▾, a dashed gold button that says how many more there are.
  • It opens in place. The shelf drops in under the six buttons, inside the same row, above the Start in CineMode line. The grid has a fixed height and scrolls, so the window grows by one known amount and never runs off the screen at a small UI scale.
  • Groups follow the settings hubs. Atmosphere, Cameras, Visions, Interface, Style and Quality of Life, each with its hub's band color. A player who liked something here finds it under the same name later.
  • Same button, same rules. Every tile is the row's button: icon, name, the In CineMode / 4 scenes / Off tag for the level hovered, Stop while it runs, greyed with a tooltip when it can't run (in a fight, mounted). Hover fills the description box.
  • Turn on, right there. A tile whose feature is off in the profile you're trying gets a small Turn on button. It adds that feature to the profile, and the tag changes to "On: you turned it on". Picking another level card resets it, since that's a different profile. Without this a player sees Duel Vision, likes it, and can't find it again.
  • Only things that play. Every tile on the shelf shows something. Features with nothing to see (wheels, the keyboard map, talent links) are one line of links under the grid, "Also in Cinematic", each opening its page with a Back to the welcome window. Search finds those too.
  • The tour leads. ▶ Watch the tour · 1½ min sits in the row's header, so it is there before the shelf is opened: your UI fading, the letterbox and tint, a camera, Vitals, Emote and Card Visions, a teleport. The Shoulder Cam joins after the camera only once the player has said yes to its experimental camera setting (picking its level, or its own button); a tour shouldn't agree to that for them. Inside the shelf, the same button plays the open group.
  • One notice in a fight. Rather than every tile explaining itself in a tooltip, the shelf shows one line at the top ("You're in a fight. The demos come back when it ends.") and the tiles grey out together. Tick "Pretend you're in a fight" above the mock to see it.
  • It remembers. Open or closed and the last group are saved, so a player who came back from Customize lands where they were.

Three kinds of demo

Test exists

The feature already has a Test on its page or in the dev Demo Hub. It needs an entry in DEMOS in ShowMe.lua (start, stop, running, a tip) and nothing else.

Needs a new demo

It shows in the world but has no Test yet. Each needs a short fake moment, like the made-up race Damage Vision's Test uses.

Link to its page

It is a tool or a look picked from a list, with nothing to play. It gets no tile: it is a link in the "Also in Cinematic" line that opens its page over the welcome window.

Build order

Fading UI demo

The addon's main idea, and today it has no demo. Fade the UI out the way the level's CineMode would, hold it, bring it back, with the welcome window faded as the camera demos do. It goes in the row too, as its first button.

The shelf, with what already plays, and Turn on

The See all button, the shelf, groups, search, the fight notice and the saved open state in Welcome.lua, reusing the row's button code for tiles. Fill it with the green tiles: they only need DEMOS entries, most of which the Demo Hub already calls (camera Tests, Cards, Damage Vision, Death Vision, Duel, Cooldown Flash, My Shots). Turn on writes the feature's switch into the profile being tried. Check the window's height in game at the smallest UI scale here, before going further: if the shelf doesn't fit, it becomes its own page of the window, as Customize is.

The tour and the page links

Watch the tour in the row's header and Play all per group, run as the Demo Hub runs its reels. The "Also in Cinematic" links need one helper that opens a page by name from the welcome window and returns to it, which Customize partly has.

The other new demos, one commit each

The amber tiles: Mouseover, Heal Vision, Nameplates, Chat Bubbles, Combat Text, Skyriding Cam. Each joins the shelf when it's done; until then it is in the link line. Tips stay one sentence each, for the eight languages.
