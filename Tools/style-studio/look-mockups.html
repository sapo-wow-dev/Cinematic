Style Studio: three looks

The same window three ways: Nameplates › Target, the Name part picked, the same settings and preview. Only the look changes, and the editor underneath stays as built. Pick one, or name what to take from each.

Look A

Game-native

Looks like part of WoW. The game's own dialog frame with a gold edge, Friz headings in gold sentence case, red-and-gold game buttons, the game's dropdowns, sliders and check boxes, and the left list styled like the game's Settings tree. Text is bigger and there are fewer boxes: each setting is a label beside its control. With a theme picked, the frame wears that theme's edge and corners.

Look B

CQL editor, calmer

The CQL editor you liked, with half the clutter. The same flat panel and colored band squares. No all-caps headers: the picked part's name is the heading. Each choice is one segmented control, nothing is outlined twice, and the type is bigger with more air between rows. It's the closest to what's built now, minus the noise.

Look C

Dressed in your theme

The Studio wears the theme you picked, shown here as Gilded Codex, using the corner and panel art the themes already have. Rounded cards, gold pill buttons, a big vignetted stage and large tiles for fonts. It's the most decorative of the three: each theme changes it, and with "The game's" theme it falls back to Look A.
